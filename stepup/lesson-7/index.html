The language of good data

Accuracy and precision

The targets showed that a set of results can be precise without being accurate. In chemistry, accuracy is how close a measurement is to the true value. Precision is how close repeated measurements are to each other. A precise set of results agrees with itself, but that does not mean it is right.

Water boils at 100.0 °C at sea level. Two groups measure it three times.Group 1: 99.8, 100.1, 99.9 °C. Close together and close to 100.0, so accurate and precise.Group 2: 97.1, 97.2, 97.0 °C. Close together but about 3 °C low, so precise but not accurate.

Quick check. Group 3 gets 96.0, 104.0 and 100.5 °C. How would you describe their results?

Worked answer
The average is 100.2 °C, close to the true value, but the results are spread out. They are accurate on average but not precise, like Archer C.

Random and systematic errors

Every measurement has some uncertainty, and the type of error explains the pattern in the results. A random error changes from one trial to the next, so it scatters results above and below the true value. Reading a thermometer by eye is an example. Random errors reduce precision, and repeating and averaging reduces their effect.

A systematic error pushes every result the same way by the same amount. A balance that is not zeroed, or a thermometer that always reads 2 °C high, causes one. Systematic errors reduce accuracy. Repeating does not help, because every repeat has the same error. You must fix the equipment or the method.

A mistake, such as spilling a sample or misreading a scale once, is not an error. Do that trial again.

Quick check. A balance shows 0.20 g with nothing on it, and the student does not notice. What kind of error is this?

Worked answer
Every mass will be 0.20 g too high. That is a systematic error, and it affects accuracy.

Repeatability and reproducibility

Scientists trust a result more when it can be repeated. VCE uses two words for this. Repeatability means the same person, using the same method and equipment, gets close results when they repeat the experiment. Reproducibility means different people, in different labs or with different equipment, also get close results.

Reproducibility is the stronger test. A result that only one person can get might come from a fault in their own equipment.

Quick check. A class in another school follows the same method and gets the same result as you. What does this show?

Worked answer
Different people with different equipment got the same result, so it shows reproducibility.

Outliers

An outlier is a result that is far from the others in a set. It is often caused by a mistake, such as an air bubble in a burette. If you can find a likely reason, leave the outlier out of the average and say so in your report. Do not leave out results just because you do not like them.

A student does four titrations. The titres are 22.45, 22.50, 23.90 and 22.40 mL.23.90 mL is far from the others, so it is an outlier.average = 22.45 + 22.50 + 22.403 = 22.45 mL

Validity

An experiment is valid if it really tests what it claims to test. Only the independent variable should change, and every other variable that could affect the result must be controlled. A valid conclusion must also be supported by the data that was collected.

Accurate and precise data can still come from an invalid experiment. If two things change at once, you cannot tell which one caused the result.

Quick check. A student tests how temperature affects reaction rate. They also use a different concentration of acid at each temperature. Is the experiment valid?

Worked answer
Two variables changed at once, so the experiment is not valid. Concentration should be kept the same.

Worked answer

Fuels. A student compares how much energy five fuels release by heating water. They use a different volume of water for each fuel. What is the problem?

Worked answer
The volume of water affects the temperature rise, so it must be controlled. With it changing, the experiment is not valid.

Scattered results. A student's titres are spread out above and below the expected value. How can they reduce this effect?

Worked answer
Spread above and below the true value is random error. Repeating and averaging reduces its effect.

Same student, next day. The same student repeats the experiment with the same method and equipment, and gets very close results. What does this show?

Worked answer
The same person used the same method and equipment, so this is repeatability.

Why does averaging more trials not fix a systematic error?

Worked answer
Random errors go up and down, so they cancel when averaged. A systematic error is the same in every trial, so it stays in the average.
