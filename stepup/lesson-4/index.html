Count the atoms

A chemical formula is a recipe for one particle. The small numbers tell you how many of each atom it has, and a big number in front tells you how many particles there are. Counting atoms is the first skill in balancing.

Your taskCount the atoms in each formula, then decide whether each equation is balanced.

How many O atoms are in H2SO4?

Worked answer
The small 4 after O means 4 O atoms.

How many H atoms are in 3H2O?

Worked answer
Each water has 2 H atoms, and there are 3 waters. 3 × 2 = 6 H atoms.

How many O atoms are in Ca(OH)2?

Worked answer
The 2 after the bracket doubles everything inside it. OH × 2 gives 2 O atoms.

How many O atoms are in 2Al2(SO4)3?

Worked answer
Inside one Al2(SO4)3: 4 × 3 = 12 O atoms. There are 2 of them, so 2 × 12 = 24 O atoms.

Balanced or not?

H2 + Cl2 → 2HCl

Balanced. 2 H and 2 Cl on each side.

H2 + O2 → H2O

Not balanced. There are 2 O atoms on the left but only 1 on the right.

2Mg + O2 → 2MgO

Balanced. 2 Mg and 2 O on each side.

N2 + H2 → 2NH3

Not balanced. The right has 6 H atoms, but the left has only 2. It needs 3H2.

CaCO3 → CaO + CO2

Balanced. 1 Ca, 1 C and 3 O on each side.

Balancing equations

Why equations must balance

In the warm up, some equations had more of an atom on one side than the other. That cannot happen in a real reaction. In a reaction, the bonds between atoms break and new bonds form, so the atoms are rearranged into new substances. No atom is created or destroyed. This is called conservation of mass, and it is why the total mass before and after a reaction is the same.

Quick check. In the picture, how many water molecules form from 2 hydrogen molecules?

Show the answer
2 water molecules. 2H2 + O2 → 2H2O

Numbers in front, not inside

There are two kinds of numbers in an equation. A subscript is the small number inside a formula, and it is part of the substance. H2O is water, but H2O2 is hydrogen peroxide, a bleach. A coefficient is the big number in front, and it tells you how many particles there are. To balance an equation, you may only change the coefficients.

A coefficient multiplies the whole formula. 3H2O means three water molecules, which have 6 H atoms and 3 O atoms in total.

Quick check. To balance H2 + O2 → H2O, what should you do?

Worked answer
2H2 + O2 → 2H2O. Only the numbers in front change.

A method that always works

Balancing by guessing gets messy. A tally table keeps track of every atom. Work through the elements one at a time, and leave H and O until last, because they often appear in several formulas. After each change, count again.

Balance Al + O2 → Al2O3.Count: left has 1 Al and 2 O. Right has 2 Al and 3 O.The O atoms are 2 and 3. The lowest number both go into is 6, so use 3O2 and 2Al2O3.Now the right has 4 Al, so put 4 in front of Al.4Al + 3O2 → 2Al2O3 (4 Al and 6 O on each side)

Keep polyatomic ions together

Some groups of atoms, such as sulfate (SO4), nitrate (NO3) and phosphate (PO4), often stay together through a reaction. If the same group appears on both sides, count it as one unit instead of counting every S and O. This makes balancing much quicker.

Balance CaCl2 + Na3PO4 → Ca3(PO4)2 + NaCl.Ca: the product has 3, so use 3CaCl2.PO4: the product has 2 groups, so use 2Na3PO4.Now the left has 6 Na and 6 Cl, so use 6NaCl.3CaCl2 + 2Na3PO4 → Ca3(PO4)2 + 6NaCl

State symbols

A balanced equation can also show the state of each substance. This matters in chemistry, because the same substance behaves differently as a solid or dissolved in water. State symbols go straight after each formula.

SymbolMeaningExample
(s)solidMg(s)
(l)liquidH2O(l)
(g)gasCO2(g)
(aq)dissolved in water (aqueous)NaCl(aq)
Sodium reacts with water.2Na(s) + 2H2O(l) → 2NaOH(aq) + H2(g)Sodium hydroxide dissolves in the water, so it is (aq). Hydrogen bubbles off as a gas.

Quick check. Which state symbol shows sugar dissolved in water?

Worked answer
Dissolved in water is (aq). (l) is only for a pure liquid, such as water itself.

Balancing real reactions

Core questions

1. Magnesium in acid.

Mg + HCl → MgCl2 + H2
Leave a box empty if the number is 1.
Worked answer
MgCl2 has 2 Cl, so use 2HCl. That gives 2 H, which makes 1 H2.
Mg + 2HCl → MgCl2 + H2

2. Making ammonia (the Haber process).

N2 + H2 → NH3
Leave a box empty if the number is 1.
Worked answer
N2 has 2 N, so use 2NH3. That has 6 H, so use 3H2.
N2 + 3H2 → 2NH3

3. Burning methane (natural gas).

CH4 + O2 → CO2 + H2O
Leave a box empty if the number is 1.
Worked answer
C: 1 each side. H: CH4 has 4, so use 2H2O. O: the right has 2 + 2 = 4, so use 2O2.
CH4 + 2O2 → CO2 + 2H2O

4. Iron rusting.

Fe + O2 → Fe2O3
Leave a box empty if the number is 1.
Worked answer
O is 2 on the left and 3 on the right, so make 6: 3O2 and 2Fe2O3. That has 4 Fe.
4Fe + 3O2 → 2Fe2O3

5. Testing for chloride ions.

AgNO3 + CaCl2 → AgCl + Ca(NO3)2
Leave a box empty if the number is 1.
Worked answer
Keep NO3 together. Ca(NO3)2 has 2 NO3, so use 2AgNO3. That gives 2 Ag, so use 2AgCl.
2AgNO3 + CaCl2 → 2AgCl + Ca(NO3)2

6. Burning propane (barbecue gas).

C3H8 + O2 → CO2 + H2O
Leave a box empty if the number is 1.
Worked answer
C: 3, so use 3CO2. H: 8, so use 4H2O. O on the right: 6 + 4 = 10, so use 5O2.
C3H8 + 5O2 → 3CO2 + 4H2O

Leave a box empty if the number is 1.

Solid calcium carbonate reacts with hydrochloric acid. It makes calcium chloride solution, water and carbon dioxide gas. Which equation is correct?

Worked answer
CaCl2 has 2 Cl, so you need 2HCl. The states come from the description: solid, solution, liquid water and gas.

The key question. Why must a chemical equation have the same atoms on both sides? Answer in one or two sentences.

Compare with a model answer
Atoms are not created or destroyed in a reaction. They are only rearranged into new substances, so there must be the same number of each type of atom on both sides. We balance an equation by changing only the numbers in front of the formulas.
